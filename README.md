# SoulGold Reference

Trainer sheet, Pokédex and damage calculator for the SoulGold difficulty hack, served by GitHub Pages.

| Page | What it is |
|---|---|
| `index.html` | Landing page: links, level caps, exporter how-to |
| `trainers.html` | Every trainer, split by split |
| `dex/` | Porydex / Pokémon Showdown dex with SoulGold's species, learnsets, innates and every encounter |
| `calc.html` | Damage calculator (Smogon's engine) with every trainer set preloaded; imports your team |
| `soulgold_export.lua` | mGBA script: exports your party and PC boxes as Showdown sets |

Generated from the hack's source by its `design/` tools (`build_sheet.py`, `dex/build_dex.py`, `calc/build_calc.py`,
`calc/make_lua.py`, `site/assemble.py`).
